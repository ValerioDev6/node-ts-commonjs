# Node TS2

Este es un proyecto Node.js basado en TypeScript, que utiliza CommonJS y pnpm como gestor de paquetes. Además, incorpora ESLint y Prettier para mantener un código limpio y formateado, y TypeORM para gestionar las migraciones y la conexión a la base de datos.

## Requisitos Previos

- **Node.js**: Se recomienda utilizar la versión especificada en el archivo [`.nvmrc`](.nvmrc).
- **pnpm**: Instalar globalmente con:
  ```bash
  npm install -g pnpm
  ```
